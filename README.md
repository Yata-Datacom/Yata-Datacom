## 💡 How I work · 做事方式

- 🔧 **Turn repetition into tools** — if I've typed it by hand a third time, it deserves a UI and a one-click export.<br/>**把重复劳动变成工具** —— 手工敲第 3 遍的活，就该有个界面和一键导出。
- 🧪 **Tests as a safety net** — lock the current behaviour with cases before refactoring; every fixed bug becomes a regression assertion.<br/>**测试兜底** —— 先写用例锁住现状，再动刀；每个修好的缺陷都转成回归断言。
- 🔌 **Vendor-neutral first** — prefer standard protocols (SSH / DHCP / TFTP / SNMP) over proprietary fields.<br/>**厂商无关优先** —— 能用标准协议就不绑私有字段。
- 📦 **Deliverables must be self-contained** — one exe, one README, one checklist; whoever gets it can run it.<br/>**交付要自包含** —— 一个 exe、一份 README、一张校验表，别人拿到就能跑。
